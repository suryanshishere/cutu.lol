# Text editor fonts

The editor self-hosts Latin WOFF2 subsets at weight 700, downloaded from the Google Fonts CSS API on 2026-10-11. No font service requests are made by visitors. Other scripts and emoji use the browser's fallback fonts.

- Nunito Sans: https://github.com/google/fonts/tree/main/ofl/nunitosans
- Caveat: https://github.com/google/fonts/tree/main/ofl/caveat
- Roboto Mono: https://github.com/google/fonts/tree/main/ofl/robotomono

Each font's SIL Open Font License and copyright notice are included alongside its asset. The CSS uses private family aliases to avoid collisions with installed fonts. Classic retains the existing Georgia system font stack.
